# PosterPilot 项目学习台

一个独立的本地网页应用，用于从业务、模块、步骤一路理解到基础逻辑。不会启动 PosterPilot 的生产后端，也不会调用模型。

## 打开与关闭

在项目根目录双击 **开始学习.cmd**，浏览器会自动打开 `http://127.0.0.1:8879`。如果端口被其他程序使用，启动器会尝试 8880～8889。重复启动会复用本工作区已有服务，不会结束其他程序。

关闭浏览器不会停止本地服务；双击 **停止学习.cmd** 停止它。停止操作核对已记录进程的程序名和服务脚本路径。学习进度保存在浏览器中，停止服务不会清空它。

需要 Python 3.10 或更新版本。启动器依次查找项目虚拟环境、当前用户的 Codex 附带运行时、系统 Python。运行本应用不需要安装 npm 或 pip 包，不需要密钥。课程和示例均在本地，不需要联网。

也可以从项目根目录手动运行：

```powershell
python apps/learn/server.py --port 8879 --open
```

## 建议从哪里开始

1. 从右上角的学习路径菜单选择「第一次来：看懂一张海报」，理解谁负责什么。
2. 在蓝色画布里点开「生成初版海报 → 找到可用的设计知识 → 先筛选，再检索 → 审核状态这一关」。输入、输出和模块关系集中在画布内，右侧用一段话解释作用和原因，并对照初级伪代码。
3. 在「运行回放」选择默认场景，先用下一步，再播放。到人工确认点自动暂停。
4. 进入「动手实验」运行默认筛选，再打开允许待审核卡片，对比两次输出。
5. 进入「可用信号」实验，把视觉分数设为 0，再把视觉信号设为不可用，观察分母与返回值的区别。

当前包含 39 个课程节点、4 条学习路径、5 个回放场景、5 个可编辑实验。部分课程附理解小题；术语可以点击解释。学习进度由用户自己标记，不把打开页面当成已经掌握。

页面采用左侧目录、中间画布、右侧说明与代码的布局。回放按钮位于画布底部，场景与实验输入在画布下方。测验、来源追踪和实验结果比较默认收起，需要时展开。桌面主操作区保持在一屏内，窄屏时说明与代码顺序排在画布下方。

## 三种执行方式的边界

| 页面标记 | 实际发生的事 | 可以据此理解什么 |
| --- | --- | --- |
| 教学回放 | 根据现有控制流编排固定示例；不执行生产流程 | 模块之间如何传递输入、输出与共享状态 |
| 仓库原函数 · 真实执行 | 从当前仓库提取白名单函数的原始 AST，不改函数体，用本地教学数据调用 | 筛选、中文字对相似度、评分函数的真实分支和局部变量 |
| 教学代码 / 规划模拟 | 执行专门编写的简化函数 | 移除次数限制或活动修订检查后的后果 |

原函数实验使用轻量数据容器，未经过完整 Pydantic 数据校验，也不执行向量库、图片模型或整个 LangGraph。它不能代替生产集成测试。源文件路径、原始行号与文件 SHA256 随结果返回，方便对应当时的代码。

运行事件里，`call` 表示进入函数，`line` 表示高亮行**即将执行**，`return` 表示已经返回。右侧变量是该事件发生时的快照。单步进入被调用函数，或用「跳过当前函数内部」「运行到当前函数返回」改变阅读粒度。超长值、集合和深层对象会截短显示。

教学回放的「模块路径」是课程位置，不是 Python 运行调用栈。回放不提供真实海报图片，只展示示例产物名称。当前字体排版的不足、独立艺术标题层和 DesignHub 的未来方案都有明确标记，不把规划当作已实现能力。

## 代码组织

- `catalog.py`：课程树、伪代码、解释、输入输出、小题、术语和路径。
- `sources.py`：读取课程指定源码，定位真实函数。
- `traces.py`：五种完整流程的确定性教学回放。
- `experiments.py` / `line_notes.py`：固定实验、Python 行级跟踪与中文阅读说明。
- `server.py`：Python 标准库服务，只监听本机。
- `web/`：原生 HTML/CSS/JavaScript 界面，不依赖外部 CDN；`workbench.js` / `workbench.css` 提供画布布局及每节的通俗说明。
- `content/overview.workflow.json`：完整流程图源文件；图由 Archify 生成。
- `.runtime/`：进程记录、日志和本地验收截图，不纳入版本控制。

## 更新课程与验证

源码对照和原函数实验每次从仓库读取；**课程文字与伪代码需要人工维护**。修改生产代码后，应运行下列检查并复核讲解是否仍准确。源码符号消失时接口会明确报错，不悄悄展示旧版本。

```powershell
python -m unittest discover -s apps/learn/tests -v
```

浏览器验收脚本需要开发机器上已有 Playwright 与 Chrome；它们不是应用运行依赖。

```powershell
# 可选：PLAYWRIGHT_MODULE 指向已有 Playwright 包，CHROME_PATH 指向浏览器。
node apps/learn/tests/browser.cjs
```

服务只开放固定实验，没有任意代码执行接口；源码读取仅限课程清单；跨站调用和路径越界会被拒绝。该界面只供本机学习，不作为联网部署服务。

启动异常时查看 `.runtime/stderr.log`。修改 Python 文件后停止再启动；修改前端文件刷新即可。

验收记录见 [VALIDATION.md](VALIDATION.md)。
