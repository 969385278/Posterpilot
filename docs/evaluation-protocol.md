# 效果评测协议

评测将工程正确性、检索质量和模型任务效果分开。开发样例用于回归，自建模拟任务用于限定条件下的对照，不代表真实用户流量。

## 比较对象与指标

|方向|对照|指标|
|---|---|---|
|路由|规则、全模型、规则加模型回退|准确率、宏F1、分类型错误、实际模型调用|
|知识检索|同一候选集合上的纯向量与混合重排|宏平均Recall@K、Hit Rate、MRR|
|记忆|历史检索与有效偏好画像|偏好取值、错误写入、漏更新、撤销及场景覆盖|
|工具选择|同来源案例与结构化策略|首选工具、参数有效性、成功选择耗时、Token|
|定向编辑|同输入和预算的版本对照|目标达成、事实保留、锁定保护、渲染可读性|

## 冻结与执行

1. 运行前保存输入、标签、模型配置、依赖与代码指纹。标签不发送给被测模型。
2. 区分预检、主实验和重复检查。共享语义模板或背景的任务记录家族关系，不视为独立用户。
3. 对照保持输入、可用工具和预算一致；交错运行降低服务时段差异。
4. 保存逐次请求、响应、失败、工具动作与产物。超时和错误保留在分母内。
5. 复测新建目录，不覆盖旧结果。测试集用于调优后，不继续称为未见验收集。

## 结论边界

- 准确率、召回率、任务成功率采用各自明确的分母，不能互相替代。
- 调用次数或输入Token减少不等于账单同比下降；同时报告准确率退化和重试。
- 不同可用信号、目标或评分权重下的综合分不能直接比较。
- 已确认画像的读取准确率，不代表从自然对话提取、巩固到生成的端到端准确率。
- 失败、负结果和无效实验保留用于审计；无效轮次不混入有效统计。
- 检索对照在小型审核知识库上没有观察到混合排序的主指标增益；决策卡替换上下文实验也不能直接代表当前追加式生产链路。
