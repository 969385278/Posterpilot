## 评测边界

简历中的 200/100/60/40/12 等样本量以及所有百分比是待核验的实验主张。
不得把这些数值编进程序作为结果，不得把为测试构造的样例称为独立人工标注集。
功能测试、离线演示、真实模型实验分别记录。只有保留固定数据、对照条件、
原始逐条输出与运行配置的实验才能支持效果主张。

## 2026-09-24 第一阶段实现

## 2026-09-24 第三阶段：素材治理和真实语义检索

### 当前实现

- `VisualAssetService` 提供本机 SQLite 素材库和规范化 PNG 存储；支持静态 PNG/JPEG/WebP，
  限制编码大小和解码像素数，处理 EXIF 方向，保留透明度并校验保存图片的内容哈希。
- 以解码像素去重，重复导入不会新建另一张素材；新来源保留原文件哈希且触发重审。
  dHash 只提示可能相似，不自动合并；主色和上中下边缘密度是像素统计，不冒充 OCR 或语义构图。
- 素材保留作者、外部来源链接、使用权、描述、风格、适用场景、文字、构图及限制。
  发布需显式确认所有来源的使用权和资料；修改后回到候选，版本冲突拒绝覆盖。
- 视觉模型补全使用现有 Ark Vision 接口，返回经过 Schema 校验的候选，编辑采纳与审核分别进行。
  模型建议不覆盖现有资料，不推断版权，生成建议期间发生并发编辑则拒绝写入旧结果。
- 检索先过滤审核状态与场景，再使用文本向量余弦和词法重合加权排序，返回来源、版本和分项依据。
  向量绑定资料版本、Ollama 模型名及实际权重摘要；模型变更、资料修订、撤回和损坏图片均受到保护。
  只有词法可用时明确标记 `lexical_fallback`，不假装语义检索成功。
- 已接入真实 LangGraph `plan_design`：将审核素材描述、主色、来源和限制提供给模型作为低优先级
  参考，保留用户明确选择优先。每轮证据、最终结果及操作台显示引用来源。
  问答助手新增 `search_visual_assets` 工具和版本化来源引用。
- PosterHub“视觉素材”页面支持上传、编辑、模型候选、审核、撤回、索引与检索验证。
